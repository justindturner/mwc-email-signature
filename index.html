Install it

Set up all three. Paste straight into the signature box; don't retype anything.

Gmail on a computer

  1. Copy the Full signature.
  2. Gmail gear → See all settings → General → Signature.
  3. Create new, name it “MWC full”, click in the box and paste.
  4. Copy the Reply version and create “MWC reply” the same way.
  5. Under Signature defaults: MWC full for new emails, MWC reply for replies and forwards.
  6. Tick Insert signature before quoted text, then Save Changes at the bottom.

Gmail phone app

  1. Copy the Phone app version.
  2. App settings → your account.
  3. Signature settings (iPhone) or Mobile signature (Android), turn it on, paste.

The app only takes plain text, so this one has no logo or photo.

Outlook

  1. Copy the Full signature.
  2. New Outlook or web: Settings → Account → Signatures. Classic Windows: File → Options → Mail → Signatures.
  3. Add new, paste, repeat for Reply, set the defaults, save.

If pasting drops the formatting, use Show HTML → Copy code.

Fonts are the brand fonts, Montserrat and Barlow Condensed. People who don't have them installed see Arial in the same layout; email can't send fonts along with a signature. Images load from this repo's assets/ folder. Never rename or delete files there: every signature in use points at those URLs.
